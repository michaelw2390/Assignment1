# Introduction to Programming - Python Exercises

This repository contains my Python coding exercises and solutions for Chapters 1 through 4 of [*Introduction to Programming Using Python*](https://gastate.view.usg.edu/d2l/le/content/3694719/viewContent/78150249/View). These exercises were completed as part of my Introduction to Programming course (Fall 2026).

## 📚 Table of Contents

The repository is organized by chapter, covering the fundamental concepts of Python programming:

* **[Chapter 1: Introduction to Computers, Programs, and Python](./Chapter_1)**
  * Basic console output, understanding the Python environment, and introductory concepts.
* **[Chapter 2: Elementary Programming](./Chapter_2)**
  * Variables, assignments, basic arithmetic operations, and evaluating expressions.
* **[Chapter 3: Mathematical Functions, Strings, and Objects](./Chapter_3)**
  * Using the `math` module, processing string characters, and an introduction to Python objects.
* **[Chapter 4: Selections](./Chapter_4)**
  * Boolean expressions, `if` statements, two-way `if-else` statements, and nested conditional logic.
